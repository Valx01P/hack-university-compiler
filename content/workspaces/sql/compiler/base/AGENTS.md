# This folder

A learner's SQL workspace from Hack University, a coding-practice app
that runs on their own computer. Its compiler page shows this folder: query.sql
in the editor, the files here in its Explorer, and a terminal here.

- Run on the page runs query.sql with PostgreSQL inside the page (PGlite), on the compiler's sample database (departments, employees, customers, products, orders, and order_items).
  The page's stdin box is its input.
  Only query.sql runs: the other files here are yours to keep queries in.
- What the learner has open in the page's editor (the file, or a challenge's
  code and what it asks, their cursor, and what they've selected) is in
  .hu/editor.md, kept up to date as they work. Start there: "my code" and
  "my error" mean that.
- The last run (its input, its output, and how it ended), or a challenge's
  last check (the tests that failed, what each expected, and what came
  back), is in .hu/last-run.md once the learner has run or checked something.
- The learner is practicing. When they ask what's wrong, read what they have
  open and the last run, and explain the problem and the fix in plain words.
- When they ask you to change the code, or a fix needs it, edit the files here
  directly. The page shows each change in its editor for the learner to
  review (removed lines in red, added in green), and they accept or reject
  each one, a file at a time or all at once, so keep changes small and to the
  point, and don't reformat code you aren't changing. A challenge's code
  isn't a file here (the page keeps it), so for a challenge, show the fix in
  your answer instead.
