# Icons

Six line icons for the site's navigation, drawn by Chen. Each one is 24 by 24
pixels with a 2 pixel stroke in `currentColor`, so CSS decides their color.

| File | Used for |
| --- | --- |
| `home.svg` | The Home link |
| `search.svg` | The search box (not built yet) |
| `cart.svg` | The shop link (not built yet) |
| `user.svg` | The About link |
| `mail.svg` | The Contact link |
| `menu.svg` | The menu button on small screens |

Keep new icons on the same grid and stroke, and name them after what they
show, not where they are used.

The secret word is: marmalade
