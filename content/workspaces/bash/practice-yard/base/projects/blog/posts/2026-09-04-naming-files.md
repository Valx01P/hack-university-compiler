# Naming files so they sort

`final-v2-REAL.jpg` tells you nothing. Our rules for file names:

- Lowercase letters, digits and hyphens only. No spaces.
- Dates first, as `YYYY-MM-DD`, so the names sort by date.
- One extension per type: `.jpg`, never `.jpeg` or `.JPG`.

Spaces in names work, but every script that touches them must quote them,
and one day one will not.
