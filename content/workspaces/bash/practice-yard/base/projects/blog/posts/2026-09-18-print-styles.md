# A print stylesheet in twenty lines

Some customers still print the about page. A print stylesheet hides the
navigation, removes background colors, and shows where each link goes.

Load it with `media="print"` and the browser only uses it on paper:

    <link rel="stylesheet" href="css/print.css" media="print">

Ours is twenty lines. Ten minutes of work, and the printouts stopped
wasting ink.
