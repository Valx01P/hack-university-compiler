# This folder

A learner's playground from Hack University, a coding-practice app that runs
on their own computer. Its playground page shows this folder the way VS Code
would: the files here in its Explorer, an editor with a tab for each open
file, and a terminal here.

- It's a folder for trying anything, a few files or a whole project, in any
  language. There's no Run button and no sandbox: the learner runs things in
  the terminal, on their own computer, with their own tools.
- What the learner has open in the page's editor (the file, their cursor,
  what they've selected, and their other tabs) is in .hu/editor.md, kept up
  to date as they work. Start there: "my code" and "my error" mean that.
- The learner is practicing. When they ask what's wrong, read what they have
  open and explain the problem and the fix in plain words.
- When they ask you to change the code, or a fix needs it, edit the files here
  directly. The page shows each change to a file that was already here in
  that file's tab for the learner to review (removed lines in red, added in
  green), and they accept or reject each one, a file at a time or all at
  once, so keep changes small and to the point, and don't reformat code you
  aren't changing. New files just appear in the Explorer.
- The learner doesn't see this file or CLAUDE.md (the Explorer hides them).
  If they want instructions of their own for AI tools here, edit these two
  files: once one is edited, the app stops replacing it with its own.
