# This folder

A learner's TypeScript workspace from Hack University, a coding-practice app
that runs on their own computer. Its compiler page shows this folder: main.ts
in the editor, the files here in its Explorer, and a terminal here.

- Run on the page runs main.ts with TypeScript 7.0.2 on Node 26.12.0, in a container on this computer (the app's runner).
  The page's stdin box is its input.
  Only main.ts goes to the runner (it runs one file), so the other files here
  are for the terminal.
- What the learner has open in the page's editor (the file, or a challenge's
  code, their cursor, and what they've selected) is in .hu/editor.md, kept up
  to date as they work. Start there: "my code" and "my error" mean that.
- The last run (its input, its output, and how it ended) is in .hu/last-run.md
  once the learner has run something.
- The learner is practicing. When they ask what's wrong, read what they have
  open and the last run, and explain the problem and the fix in plain words.
- When they ask you to change the code, or a fix needs it, edit the files here
  directly. The page shows each change in its editor for the learner to
  review (removed lines in red, added in green), and they accept or reject
  each one, a file at a time or all at once, so keep changes small and to the
  point, and don't reformat code you aren't changing.
