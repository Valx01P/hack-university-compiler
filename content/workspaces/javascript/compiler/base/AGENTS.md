# This folder

A learner's JavaScript workspace from Hack University, a coding-practice app
that runs on their own computer. Its compiler page shows this folder: main.js
in the editor, the files here in its Explorer, and a terminal here.

- Run on the page runs main.js with Node 20 in a sandbox (Piston).
  The page's stdin box is its input.
  Every other file here goes with it, beside main.js, so the program can read
  them (file input and output) or use them as more of its code.
- The last run (its input, its output, and how it ended) is in .hu/last-run.md
  once the learner has run something.
- The learner is practicing. When they ask what's wrong, read their code and the
  last run, explain the problem and the fix in plain words, and let them make
  the change, unless they ask you to.
