# Next.js playground

A fresh Next.js 16 app, as `create-next-app` sets one up: TypeScript, the App Router, Tailwind
CSS, ESLint, Cache Components, and the `@/*` import alias. One thing differs: the Geist fonts
come from the `geist` package as local files, because this sandbox has no internet and
`next/font/google` would have to download them.

## Run it

The development server starts when the playground opens and prints the address it listens
on. The preview shows that page, and it updates as you save (Fast Refresh). To run it from
the terminal yourself:

```bash
npm run dev
```

| Command | What it does |
| --- | --- |
| `npm run dev` | Development server with Fast Refresh. Server logs print in this terminal |
| `npm run build` | Production build. Prints the route table (`○` means prerendered as static content) |
| `npm run start` | Serves the production build. It uses the same port as the dev server, so stop that first |
| `npm run lint` | ESLint with the Next.js rules |
| `npx tsc --noEmit` | Type-checks the project with TypeScript 7 (run the dev server or a build first, so the route types exist) |

## Where to start

Open `app/page.tsx`, change the heading, and save. Every file in `app/` that is named
`page.tsx` is a route: `app/about/page.tsx` would be `/about`.

| File | What it does |
| --- | --- |
| `app/layout.tsx` | The root layout: `<html>`, `<body>`, the fonts, and the page title |
| `app/page.tsx` | The home page, `/` |
| `app/globals.css` | Tailwind CSS and the color and font variables |
| `app/favicon.ico` | The tab icon |
| `public/` | Files served from the site root: `/next.svg` is `public/next.svg` |
| `next.config.ts` | Next.js settings: Cache Components and Partial Prefetching are on, and `allowedDevOrigins` lets the preview load the dev server from `127.0.0.1` too |
| `tsconfig.json` | TypeScript settings, including the `@/*` alias for the project root |
| `eslint.config.mjs` | ESLint settings |
| `postcss.config.mjs` | Loads Tailwind CSS |
| `next-env.d.ts` | Generated by Next.js for its types. Never edit it |
| `AGENTS.md` | Notes for AI coding agents, written by `create-next-app` |

## Good to know

- `npm install` works only for packages this image already holds, since there is no internet.
- The package named `typescript` is the TypeScript 6 API, which ESLint's TypeScript parser
  and `next build`'s type check load. `npx tsc` runs TypeScript 7 (`@typescript/native`).
- `"overrides": { "eslint": "$eslint" }` in `package.json` lets the React, import, and
  accessibility plugins inside `eslint-config-next` use this project's ESLint 10. They work
  with it, but their package metadata still lists only ESLint 9.
